## 2. Спосіб запуску (через Live Server)

Збирати нічого не потрібно: це статичний сайт на HTML і CSS.

1. Встановіть редактор [Visual Studio Code](https://code.visualstudio.com/).
2. Встановіть розширення **Live Server** (автор Ritwick Dey).
3. Відкрийте теку проєкту через **File → Open Folder**.
4. Відкрийте `index.html`, натисніть правою кнопкою миші й оберіть **Open with Live Server** (або кнопку **Go Live** внизу праворуч).
5. Сайт відкриється за адресою `http://127.0.0.1:5500/`.

Відкривати файли подвійним кліком теж можна, але шляхи до CSS і зображень надійніше перевіряти саме через Live Server.

## 4. Опис дизайн-системи

Повний довідник із прикладами та кодом для копіювання: **[styleguide.html](styleguide.html)**.

Дизайн-система складається з трьох рівнів:

1. **Токени** (змінні CSS у `:root` файлу `css/style.css`):
   - кольори: `--color-primary`, `--color-primary-light`, `--color-primary-soft`, `--color-accent`, `--color-text`, `--color-text-muted`, `--color-surface`, рамки й поля вводу;
   - розміри шрифту `--font-size-*`, відступи `--space-*`, радіуси `--radius-*`, тіні `--shadow-*`.
2. **Компоненти** (класи): `.btn`, `.card` (`.featured`), `.badge`, `.media`, `.stats`, `.back-to-top`, форма (`.field`), таблиця, цитата.
3. **Шаблони сторінок:** шапка з меню й футер, адаптивна галерея карток `.card-grid` (CSS Grid, `auto-fit`), 12-колонкова сітка `.page-grid`.

Правило супроводу: змінили `style.css` — оновіть довідник.

Шрифти не підключаються з інтернету: використовуються системні (Segoe UI, Roboto, Helvetica Neue, Arial; для коду — Fira Code, Consolas, Courier New). Бібліотеки та фреймворки не застосовуються.

## 6. Відомі обмеження

- **Контраст кольорів.** Білий текст на `--color-primary` має контраст близько 3,3:1, що нижче норми WCAG AA (4,5:1) для звичайного тексту. На білому тлі `--color-primary-light` має лише близько 1,3:1, тому при наведенні білий текст на кнопці читається погано.
- **Дубльовані токени.** Є дві шкали відступів із однаковими значеннями (`--space-1…6` і `--space-xs…2xl`) та два червоні кольори (`--color-accent`, `--color-accent-new`).
- **Адаптивність.** Сітка `.page-grid` не має медіазапитів, тому на дуже вузьких екранах колонки не перебудовуються.
- **Форми.** Обов'язкові поля позначено лише смугою зліва; форми не надсилають дані на сервер (немає серверної частини).
- **Фото шапки** завантажується локально з `img/photo-1.jpg`; без цього файлу шапка втрачає фон.
